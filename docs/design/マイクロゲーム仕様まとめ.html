1ミニゲームは 0.8 + 12 + 0.35 = 13.15秒。90秒プレイなら 1プレイあたり約6〜7ミニゲーム、合計20問前後になる。

「12秒で3問」の効き方 — 1問あたりの時間が固定ではない

制限時間はミニゲーム全体に対して1つだけで、1問ごとには区切られない。つまり12秒をどう配分してもよい。1問目に5秒かけて、2問目を3秒、3問目を4秒でも成立する。

これは問題ごとに必要な時間がばらつく種目に効く。M1(手紙の長さで読む時間が変わる)やM3(組み合わせが見つかるまでの試行回数が変わる)は、1問ずつ時間を切られると理不尽になりやすいが、まとめて12秒なら易しい問題で稼いだ余裕を難しい問題に回せる。

結果として、「1問あたり7秒では読解ゲームとして厳しい」という懸念(§1-1)が構造的に緩和された。

速く解くこと自体が報酬になる

3問正解した時点でミニゲームは終わり、残り時間を待たずに次の種目へ移る。速く解けばそのぶん90秒の中でこなせるミニゲーム数が増え、スコアが伸びる。

企画書にあった「残時間ボーナス」を別途用意しなくても、この構造自体が残時間ボーナスとして機能する。プランナーが「M5では残時間ボーナスが構造的に発生しない」と指摘していた問題も、これで解消する。

「あくまで誤答だけが失敗」

時間切れで解けなかった問題は失敗として扱わない。コンボも切れない。これにより:

  • 「分からないから飛ばす」が戦略として成立する。迷った問題に時間を使い切るより、当てずっぽうで外すほうが損になる — 誤答のほうが重いので、慎重さが報われる
  • 下手な人でもコンボが理不尽に切れない。切れるのは自分が間違えたときだけ
  • 「クリアできなかった」という状態のペナルティが実質ない。正解した数だけが積み上がる
企画書からの撤回 — レベル制は持たない

企画書は「難易度が経過時間ベースで5段階に上昇し、制限時間が基準値から短縮される(Lv5で×0.62)」という設計だったが、これは撤回する。基準時間は種目ごとに固定し、プレイ中に短縮しない。

難易度は問題ごとの当たり外れで作る(→ §0-5 原則1)。

0-5. 全種目に適用する設計原則 変更提案

#原則理由
1レベル制を持たない難易度をシステムとして段階制御しない。レベル選択の仕組みも作らない。問題は難易度のばらつきを持つプールからランダムに引くだけで、易しい問題と難しい問題が交互に来る「当たり外れ」が緩急になる。制限時間は種目ごとに固定し、プレイ中に短縮しない
2視線の着地点を不変にする選択肢の位置・サイズ・数を問題ごとに変えない。90秒プレイで視線の再探索は無視できないロス。原則1によりレベル連動の増減がなくなったので、この原則はより単純に守れる(常に同じ数を同じ位置に置くだけ)
3理不尽の線引き「もう一度見れば分かる」は良い難しさ。「見ても一意に決まらない」は理不尽。ただし「知らないものに出会う」こと自体は許容する — それは学びとして扱う(→ §1-5、§2-1)
4文字表記は教育漢字 + 全行分かち書き読速を確保する。ベタ書きのひらがなは読速が壊滅的に落ちる。漢字は小学校で習う範囲(教育漢字1026字)を上限とし、分かち書きは漢字の有無によらず全行に適用する。これは日本語版のルール。英語版は別途定める必要がある
5説明がいらないほど単純なルールにする種目ごとのチュートリアルを作らなくて済む水準を目指す。説明が必要になった時点で、そのルールは複雑すぎると考える。判断に迷ったらルールを削るほうへ倒す。素案 §4「ゲーム開始直後にプレイヤーが何をすればいいか分かること。複雑なルール説明を必要とするミニゲームは避ける」に立ち返るもの

機種差でコンテンツがバナーと被らないための方針

上の数値は設計上の目安であって、固定ピクセルで実装してはいけない。iPhone は機種によってセーフエリアもアダプティブバナーの実高さも変わる(ノッチ機 / Dynamic Island 機 / ホームボタン機 / 画面比 19.5:9 と 19.3:9 など)。固定値で組むと、必ずどれかの機種で被る。

実装の原則:

  • 下端の予約高さは実行時に計算する。「セーフエリア下端の実測値 + バナーの実測高さ」を起動時とセーフエリア変化時に取得し、その値をレイアウトへ反映する。設計値をハードコードしない
  • コンテンツ領域は上下ストレッチにする。HUD は上端基準、バナー予約とタップ対象は下端基準にアンカーし、余った縦幅はすべてコンテンツ領域が吸収する。これで縦に長い端末でも他の要素が崩れない
  • バナーは「読み込めたら表示」ではなく「領域は常に確保、中身だけ差し替え」。広告の読み込み成否でレイアウトが動くと、タップ位置がずれて誤タップの原因になる
  • 下端に最小マージンを設ける。バナー予約領域の上に固定の余白(40px程度)を置き、計算誤差が出ても直接は接しないようにする
  • 検証は最小・最大の2端末で行う。セーフエリアが最も小さい機種と最も大きい機種の両方で、タップ対象がバナーに被らないことを確認する

なお、2つの壁打ちで下端の見積もりが 256px と 280px に割れている(Q0-2)。実行時取得にすればこの食い違い自体が問題でなくなるが、設計時のレイアウト確保量としてはどちらかに寄せておく必要がある。

1-1. この種目が抱える構造的な弱点

未解決の設計課題

M1だけ操作密度が極端に低い。1通あたりタップは1回で、大半が「読んでいる=手が止まっている」時間になる。他3種はほぼ手が動き続けるので、90秒という短い枠ではこの「止まり」がテンポを壊しかねない。

プランナーは「読解ゲームで焦らせるのは、難しくしているのではなく理不尽にしているだけ」として、読む間はタイマーを停止する2フェーズ制を推奨した。ディレクター判断で単一フェーズを採用。

対策として3つが打たれている。① 文字数上限を企画書の45文字から35文字へ10文字ぶん締めた(§1-6)② 漢字の範囲を教育漢字まで広げ、かなを減らして読速を上げた(§1-6)③ 「12秒で3問」構造により、1問あたりの時間が固定でなくなった(§0-3)。

③が最も効いている。当初は「1問7秒」で区切られていたため、長めの手紙に当たると即座に理不尽だった。12秒をまとめて配分できるようになったことで、短い手紙で稼いだ余裕を長い手紙に回せる。平均で1問4秒だが、読解に5〜6秒かけられる問題があってよい。

加えて、時間切れがコンボを切らない(§0-4)ため、読み切れずに終わっても罰がない。この種目にとって最も重要な緩和で、「読むのが遅いと損をする」設計ではなくなった。

型C「大量」の絶対条件

手紙にはほしいものがたくさん書かれているが、4択のうち該当するのは1つだけにする。ほしいものが2つ選択肢に入っている状況を作ってはいけない(正解が一意でなくなる)。

上の例では、手紙に4つ(車のおもちゃ / トレカ / ゲーム / ゲーム機)書かれているが、選択肢に入っているのはゲームだけ。図かん・くつ・ボールは手紙に一切出てこない。

この型の面白さ — 情報量が多いのに、やることは「選択肢の4つが手紙に出てきたかどうか」を照合するだけ。全部を理解する必要はなく、拾えばいいという気づきが起きる。手紙を頭から丁寧に読むと間に合わず、選択肢側から照合すると速い。読み方の戦略が生まれるのがA・Bとの違い。

難しさの調整幅(型の中でのばらつき) — 手紙に書くほしいものの数(3〜5個)/ 選択肢と手紙の言葉の一致度(「ゲーム」がそのまま出るか、「あそぶ きかい」のように言い換えられているか)/ 手紙に出てくるが選択肢にないものの紛らわしさ。

各地域の輪郭の内側のみ。輪郭の外(海・区分線の上)をタップしても無反応で、不正解にはしない。

プランナー案の「各口に積んだ数を出す」を、地図の各地域に数値を累積する形で実現する。プレイ終了時、地図の上に「今日どこへ何個届けたか」という業務の証跡が残る。世界地図の上に数字が乗るぶん、ボックス案より絵として強い。
地図に描く線 確定

国境線は描かない。州(大陸)の区分線は描く。

州の区分線は仕様上の必須要素。正誤判定の単位が州である以上、どこからどこまでが1つの州なのかが見えないとプレイヤーは押しようがない。州が当たっていれば正解というルールを、線がそのまま可視化する。

一方で国境線は引かない。国境線を引くと係争地域の帰属を地図上で表明することになり、特定国での配信停止・削除要求の直接的な原因になりうる。地図上には国名も入れない。州の区分線は国境線とは性質が違い、教科書の区分に沿って引く限りリスクはごく小さい。

州の区分線を引くときの注意

区分線が通る場所は、そのまま6州区分の解釈が割れる場所と一致する。ヨーロッパ/アジア(ウラル山脈)、アジア/アフリカ(スエズ)、北アメリカ/南アメリカ(パナマ地峡)、アジア/オセアニア(インドネシア周辺)。

ただし本作ではこれらの境界にまたがる国(ロシア・トルコ・エジプト・カザフスタン等)をすべて出題から除外しているため(§2-4)、線の引き方が出題の正誤に影響することはない。教科書の区分に沿って引けば足りる。

タップの当たり判定 確定

各地域の輪郭の内側だけがタップできる。輪郭とは別に見えない領域を重ねる方式は採用しない。見た目と判定が完全に一致するので、「押したのに反応しない」「押していないのに反応した」が起きない。

輪郭の外(海・州の区分線の上)をタップしても何も起きない。不正解として判定せず、無反応とする。

無反応にする理由: ① 外した人は押し直すぶん時間を失うので、それが自然なペナルティとして機能する。誤答扱いにする必要はない。② 「輪郭の内側を押すものだ」ということが、反応がないこと自体から伝わる。次に同じミニゲームが来たときの押し方の学びになる(ディレクター判断)。

この設計は§2-1 の「あとで自分で調べられればよい」という基準とも一貫している — 明示的に教えるのではなく、プレイヤーが自分で気づく余地を残す。

地図素材に付く条件 — 作成前に確認してください

輪郭内タップを採用したことで、地図素材の作り方に2つの条件が付きます。

① 6地域をそれぞれ別の画像として書き出す。1枚のフラットな世界地図画像では、地域ごとの当たり判定・色の出し分け・カウンタ表示ができない。アジア / ヨーロッパ / アフリカ / 北アメリカ / 南アメリカ / オセアニア を別レイヤー・別ファイルに分ける必要がある。州の区分線は、隣り合う地域の輪郭が接することで自然に見えるか、線だけを別レイヤーにする。

② 小さい地域を実際の面積比より大きくデフォルメする。当たり判定が輪郭そのものになるため、輪郭の大きさがそのまま押しやすさになる。実際の面積比で描くとヨーロッパとオセアニアがApple推奨の44×44ptを下回るおそれがある。この2つは特に大きめに描いてください。

固定色は維持する(アジア=朱、ヨーロッパ=濃青、アフリカ=黄、北アメリカ=緑、南アメリカ=赤紫、オセアニア=空色)。色覚多様性への対応として地域名テキストを地図上に併記し、色が識別できなくても解けるようにする。配色の詳細は追って整理。

2-5. 難易度 確定

国の認知度は人によって違うので、それだけで難易度のばらつきは再現できている。プランナーが出したLv1〜4の段階設計(知名度でLv分け・制限時間の短縮・Lv4のみ連続2個)はすべて不要。

M2は4種の中でレベル制の廃止(§0-5 原則1)と最も相性が良い種目。同じ「フランス」という問題でも、知っている人には一瞬、知らない人には難問になる。難易度が出題側ではなくプレイヤー側にあるため、システムで段階制御する必要が元々ない。

3-4. 難易度 確定

M3の難しさは組み合わせ探索の運と勘から自然に生まれる。同じ「合計7」でも、最初に選んだ箱がたまたま解に含まれていれば一瞬で終わり、外していれば取り消してやり直すことになる。プレイヤーの試行順序という制御できない要素が、そのまま難易度のばらつきになる。

プランナーが出したLv1〜4の段階設計(整数のみ → 小数 → 単位混在 → 中身2個の合計)はすべて不要。単位をなくした時点で「単位換算」という軸自体も消えている。

3-5. 問題の自動生成 確定

手作りの問題データは不要。数値の変更と正解の組み合わせのレパートリーがあれば生成できる。単位がなくなったことで、生成もバリデーションも大幅に単純になった。

#バリデーション理由
1目標値ちょうどになる組み合わせが、6個の箱の中にちょうど1通りだけ存在する正解の一意性。複数の解があると「合っているのに違う組み合わせで正解になった」という不明瞭さが出る
2同じ数値の箱が2つ以上存在しない見分けがつかない箱があると混乱する。また、同じ数値が2つあると解が複数になりやすい
プランナー案の8条件から2条件へ

プランナーは8項目のバリデーションを挙げていたが、そのうち6項目は単位・小数に関するものだった(g は100の倍数のみ / 同じ実重量をgとkgで両方出さない / 小数は第1位まで / 上限値は整数kgのみ 等)。単位をなくした時点で、これらの条件はすべて不要になった。

残るのは正解の一意性と数値の重複禁止の2つだけ。これはディレクターの見立てどおり。

実装上の注意 — 条件1は組み合わせの数え上げになる。6個の箱に対して部分集合は63通りなので、全通り試して合計が目標値になるものが1つだけかを確認すれば足りる(計算量は問題にならない)。→ 開発確認 #14

この種目は作らない(2026-09-06 決定)

素案 5.4 の「プレゼントを数えろ」はMVPから外す。MVPはM1・M2・M3・M5 の4種になる。

不採用の理由 — プランナーの分析により、M4は「難易度を健全に上げる軸」を構造的にほとんど持たないことが判明した。企画書が挙げていた難易度手段(複合条件・重なり・動き・近い色)はすべて理不尽側に落ちる。

  • 複合条件(「赤くてリボンがない」)は視覚探索を並列から直列に落とし、22個 × 0.25秒 = 5.5秒が探索だけで消える
  • 重なりは隠れた個体を原理的に数えられない
  • 動きは数えた個体を見失う
  • 個数を増やすのは情報量が増え、時間が線形に伸びる

加えて計数速度は成人でほぼ生理的な定数で練習しても速くならないため、上達を実感しにくい種目でもあった。

5-1. この種目の固有価値 — 先読み

M5だけが持つスキル上限

企画書は「リズムに緩急がつく」としているが、それだけなら制限時間の長短でも作れる。M5は4種の中で唯一「先読み(look-ahead)」というスキルを持てる種目。ベルトに次の2〜3個が見えているので、上級者はいま指を動かしながら、目は次の箱を見て判断を済ませている。初心者は1個ずつ「見る→決める→押す」を直列に行う。この差は歴然としており、練習すれば必ず速くなり、しかも本人がその上達を自覚できる。

M1(読解速度)・M2(知識の想起)・M3(暗算)はいずれも既存能力の測定に近く、プレイ中に上達を実感しにくい。M5だけが「ゲームとしての上達」を提供する。

ベルトに次の箱が見えていることは設計上の必須要件。ここを削るとM5はただの「遅いM2」に堕ちる。

5-2. 構成とコンボ 確定

M5だけ「1問」の粒度が違う

他3種は「12秒 / 3問」だが、M5は 3問 × 3ループ = 最大9問。1問 = 箱1個。12秒で9個なら1個あたり約1.33秒で、元の設計(1個約1秒)に近いペースが保たれ、先読みが成立する。

項目決定

コンボ3問連続で当たったら1コンボ。最大9問正解で3コンボ
基準時間12秒(他3種と同じ)
1問の単位箱1個
コンボの獲得ペースが全種目で揃う

他3種は「3問正解 = 3コンボ」、M5は「9問正解 = 3コンボ」。1ミニゲームあたり最大3コンボという上限が全種目で一致する。M5の1問は個別には速く簡単なので、3問まとめて1コンボにすることで種目間の重みが釣り合う。

これにより「M5を引くとコンボが稼ぎやすい / 稼ぎにくい」という偏りが生まれない。プランナーが懸念していた「M5がコンボの処刑場になる」も「コンボ農場になる」も、どちらも回避されている。

スキップ口へ能動的に入れる方式なら、この問題が構造的に消える。プレイヤーは必ず何かを押すので、押した手応えがそのまま「処理した」という確認になる。「押さないでおく」という難しい抑制を要求しないのに、ゴミを見分けるという判断は残る。

「国旗のみ表示」は確定的に不採用(Q2-1により、調べる取っかかりである国名を消す選択肢がなくなったため)。

Q2-9チュートリアル / 12月アップデートの方向

決定(2026-09-06): 掴み役としての設計は不要(1問目をM2に固定する案は不採用)。ただしチュートリアルは実装したいとのことで、M2はそこに入れるミニゲームの候補。ルールがタップ1回で完結し最も説明しやすいため。

未検討: チュートリアルの中身(何種目を扱うか / いつ出すか / スキップできるか / 初回のみか)。

12月アップデート(プランナー案・未決): 都道府県版をM2の難易度として足すのではなく、独立した新種目M6「都道府県でしわけろ」として足す。地図方式にしたことで世界地図を日本地図に差し替えるだけになり、流用範囲がさらに広がった。同時に国を+18。

Q3-1ルール — 複数選択・取り消し可・単位なし 解決済み

決定(2026-09-06): 複数選択あり。取り消し可。合計が目標値ちょうどになったら成立し、次のそりへ移る。プランナーの「6秒で複数選択は成立しない」という指摘は、取り消し可にしたことと基準時間を6秒 → 12秒に拡大したことで解消された。プランナーの代案(箱の中身に合計を埋め込む)は撤回。

単位はなし。数値だけ。国によって単位が異なるため(kg / ポンド)。英語版で翻訳が実質ゼロになるという副次効果がある。

1回のM3でそり3台をさばく。基準時間12秒。→ 詳細は §3-1

Q3-2失敗の扱い 解決済み

決定(2026-09-06): 目標値を超えたら失敗判定。ただしやり直せる。失敗したことはトナカイの表情が悲しくなることで示す。他4種の失敗演出とは異なり、ゲームは止まらない。

M3は失敗しても続けられる唯一の種目になるため、「いま失敗した」ことを伝える手段が別途必要で、それをトナカイの表情が担う。画面を止めずに状態だけを伝えられる。

マイクロゲーム単位の失敗は「12秒で3台さばけなかった」場合のみ。そのときは他4種と同じ0.35秒の判定演出。

Q3-3画面構成と難易度 解決済み

箱は常に6個(3列×2行)。箱の絵に数値を直接書き込むことでスペースを確保する(荷札を貼る方式は不採用)。

難易度は設計しない。「人や、組み合わせの試行の噛み合わなさ次第で解けない場合が生じるため、ルールだけでばらつきは再現できる」というディレクター判断。プランナーのLv1〜4の段階設計は不要。単位をなくした時点で「単位換算」という難易度軸自体も消えている。

Q3-4問題の自動生成とバリデーション 解決済み

決定(2026-09-06): 手作りデータは不要。バリデーションは2条件のみ — ① 目標値ちょうどになる組み合わせが6個の箱の中にちょうど1通りだけ存在する(正解の一意性)② 同じ数値の箱が2つ以上存在しない。

プランナーは8条件を挙げていたが、そのうち6条件は単位・小数に関するものだった(gは100の倍数のみ / 同じ実重量をgとkgで両方出さない 等)。単位をなくした時点で不要になった。ディレクターの見立てどおり。

Q3-5演出 解決済み

採用: ① 積載メーターで視覚化(目標値の位置に赤い縦線。数値が読めなくても直感で分かる)② そりとトナカイが右へスライドして抜け、左から次が入ってくる(プランナー案の「そりが少し沈む」から拡張)③ トナカイの表情(オーバー時に悲しくなる)。

不採用: 荷札に数字を載せる(箱に直接書く方式に変更)/ 文言の業務化(「つみこみ かんりょう」等は削除)。イラストの移動で正解感が分かるため文言は不要というディレクター判断。物が動くほうが速く伝わり、言語にも依存しないので英語版でも有利。

Q3-6M3が90秒プレイに占める比率 解決済み

基準時間を12秒にした時点では、M3の1サイクルが13.15秒と突出し「最大3回出ると90秒の44%を占める」という問題があった。

Q0-9(全種目12秒 / 3問構成)で自動的に解消。全種目が同じ13.15秒になったため、M3だけが長いという状態ではなくなった。1プレイは約6〜7ミニゲームで、どの種目が引かれても所要時間は同じ。

Q3-7M3で残っている細部

オーバー判定 — 解決済み(2026-09-06)。コンボは切らない。やり直せる以上、他種目の「誤答」とは性質が違うため。M3ではコンボが切れる場面が実質なくなる(積みすぎても戻せて、時間切れも罰されない)。トナカイの表情だけが失敗を伝える。

数値の範囲 — 目標値と箱の数値をいくつからいくつにするか。12秒で3台さばくペースから逆算して決める。プロトタイプでは6レパートリーを用意する(→ §0-1)。

3台の難易度 — 1台目を易しく3台目を難しくするのか、3台とも同じプールから引くのか。

Q0-1縦画面ゾーニングとHUDの内容

ゾーニング: 上部セーフエリア160 / HUD 220 / コンテンツ 1284 / バナー160 / 下部セーフエリア96(§0-5)。実機での検証が必要。

HUD: のこり時間バー / 処理件数 / コンボ(3以上でのみ表示)。Lv表示は置かない(レベル制を持たないため)。サンタの表情はHUDに置かず結果画面に集約する(レベルアップ演出は削除されたため)。

M5 ラッピングしわけ

Q5-1「1問」の定義と構成 解決済み

決定(2026-09-06): 1問 = 箱1個。3問 × 3ループ = 最大9問で1ミニゲーム。基準時間は他3種と同じ12秒。

これで先読みが保たれる。12秒で9個なら1個あたり約1.33秒で、元の設計(1個約1秒)に近いペース。「1問=箱1個で3問だけ」にすると12秒で3個になり、ベルトがスカスカになってM5の持ち味が失われるところだった。

Q5-2コンボの数え方 解決済み

決定(2026-09-06): 3問連続で当たったら1コンボ。最大9問正解で3コンボ。

これでコンボの獲得ペースが全種目で揃う。他3種は「3問正解 = 3コンボ」、M5は「9問正解 = 3コンボ」。1ミニゲームあたり最大3コンボという上限が一致する。M5の1問は個別には速く簡単なので、3問まとめて1コンボにすることで種目間の重みが釣り合う。

プランナーが懸念していた「M5がコンボの処刑場になる」も、逆の「コンボ農場になる」も、どちらも回避されている。

Q5-3スキップ口の新設 解決済み

決定(2026-09-06): シュートは赤・青・黄の3択に加え、下部に横長のスキップ口を置く。たまに流れてくるゴミをそこへ入れる。

プランナー案より優れている。プランナーは「こわれた箱はどのシュートにも入れず素通しする」を提案していたが、この案には「見逃したのか正解したのか分からない」という問題があり、補うための追加演出が必要だった。スキップ口へ能動的に入れる方式なら、この問題が構造的に消える。「押さないでおく」という難しい抑制を要求しないのに、ゴミを見分ける判断は残る。

Q5-4カテゴリと難易度 解決済み

決定(2026-09-06): 色カテゴリと形カテゴリを用意し、1ミニゲーム内では固定(3問×3ループを通して同じカテゴリ)。色の判別が速い人と形の判別が速い人がいるため、どちらを引いたかがそのまま当たり外れになる。色や形のレパートリーを増やすことでばらつきも増やせる。

固定にしたことの効果: 9問を通して見本が変わらないため先読みが最大限に働く。ループの境目で見本を読み直す必要がなく、切り替えを伝える演出も不要で実装も軽い。

未決: 色と形それぞれの種類数。

Q5-5処理しきれなかった場合の扱い 解決済み

決定(2026-09-06): 箱を処理しきれなくてもコンボはリセットしない。M3で「12秒で3台さばけなくても失敗ではない」と決めたのと同じ方針。さばけたぶんのスコアは入る。

プランナーが警告していた「M5だけ失敗率が3〜4倍になりコンボの処刑場になる」問題は完全に解消した。取りこぼしは罰されず、間違えたときだけ罰される。提案されていたしきい値方式は不要になった — 時間切れが罰されない以上、複雑なしきい値を設ける理由がない。時間と点数の配分だけで調整できる。

Q5-6M5で残っている細部

操作方式 — プランナー推奨はタップ統一(判定ゾーンのアクティブな箱に対し、下部の固定口をタップ)。決定ログ13「タップ中心で統一」との整合。M5だけフリックを許す選択肢もあるが、その場合は決定ログの修正が必要。

フィードバックの2層構成 — アイテム単位は0.2秒・非ブロッキング(ベルトを止めない)、ミニゲーム判定は0.35秒。「演出0.35秒に揃える」共通ルールはミニゲーム単位の判定にのみ適用するという切り分けの承認が必要。

ゴミの個数 — 解決済み(2026-09-06)。1ミニゲームに最低1個、最大3個。最低1個が保証されるのでスキップ口が毎回意味を持ち、最大3個は9問中の3分の1で「仕分け」が「ゴミ探し」に変わらない上限。

ベルトの流速と投入間隔 — 12秒で9個をどう配分するかは未決。

色と形の種類数 — プロトタイプでは6レパートリー(→ §0-1)。本番でどこまで増やすかは未決。

ゲーム全体(§6〜§8)

Q7-1サンタランクの閾値を引き直す ★要対応

企画書の閾値(一人前1,200 / ベテラン2,200 / スーパー3,200 / マスター4,200)はレベル係数と残時間ボーナスが乗る前提の数字だった。両方削除したため現在の式では届かない。

概算: 1プレイ約20問。全問正解でコンボが繋がり続けた場合の平均倍率を1.5とすると 20 × 100 × 1.5 = 3,000点が上限に近い。マスター4,200は到達不可能。

決めるべきこと: 閾値をどう引き直すか。「一人前サンタ」に初回〜3回目で到達できることが達成感の初速として重要。実際の分布はプレイテストでないと分からないので、ScriptableObjectで後から調整できる形にしておき、仮値で進めるのが現実的。

Q7-2コンボ倍率のテーブルはこのままでよいか

現行(企画書の仮値): 0〜2連=1.0 / 3〜5連=1.2 / 6〜9連=1.5 / 10連〜=2.0

検証: 1ミニゲームあたり最大3コンボ、1プレイ6〜7ミニゲームなので理論上の最大コンボは18〜21連。「10連〜=2.0倍」はプレイ後半をほぼノーミスで通してようやく届く水準で、テーブルとしては妥当と考えられる。

ただし「誤答だけが失敗」という設計(§0-4)によりコンボは切れにくい。慎重に飛ばせば繋がり続けるため、実際には2.0倍に届きやすいかもしれない。プレイテストで確認が必要。

Q7-3チュートリアルの方針 解決済み

決定(2026-09-06): ゲーム起動時の初回チュートリアルは実装する。種目ごとの遊べるチュートリアルは作らない(工数がかかりすぎるため)。初出カードは静的なカード1枚のまま。

その代わりに設計原則が1つ増えた — 「そもそも種目ごとのチュートリアルが必要ないくらい、簡単で分かりやすいルールにする」。§0-5 の設計原則5として全種目に適用する。説明が必要になった時点で、そのルールは複雑すぎると考える。

これは素案に立ち返る判断でもある — 素案 §4 は「ゲーム開始直後にプレイヤーが何をすればいいか分かること。複雑なルール説明を必要とするミニゲームは避ける」としていた。

調査結果(参考): メイドインワリオもリズム天国も「読み物だけの説明機能」は持たず、両方とも遊べる形式(ワリオウェアのIndex = 遊び直せる一覧 / リズム天国のPractice = 遊べる練習パート)。ワリオウェアのIndexは 12月アップデートの「ミニゲーム一覧」候補として有力。

残る宿題: §6-4 の点検により、M3が原則5から最も遠いことが分かった(複数選択・取り消し可を説明なしでどう伝えるか)。チュートリアルの中身(何を扱うか / スキップできるか / いつでも見返せるか)も未検討。

Q7-4「忙しさ」をどこで作るか

BGMのテンポを一定にする決定により、「だんだん忙しくなる」演出手段がすべてなくなった(レベル制廃止でゲーム内容も一定、テンポも一定)。

認識しておきたいこと: 素案 §14 が目指す「めちゃくちゃ忙しいけど楽しい!」という体験は、ミニゲーム自体のテンポだけで作ることになる。90秒という短さ、12秒で3問という密度、種目が次々切り替わること、の3つが忙しさの源。

プレイテストで「忙しさが足りない」と感じた場合の打ち手を、あらかじめ考えておくとよい(制限時間を12秒より短くする / 1プレイを90秒より短くする など)。

Q7-5アセット点数の改訂を承認するか

企画書187点 → 改訂約177点。M4削除(-8)と国旗減(-18)が、M1在庫増(+8)とM5増(+6)でほぼ相殺された。→ §8-2

注意: M1の在庫アイコンが増えたのは、名前テキストを載せない決定の帰結。絵だけで何かが分かる必要があるため、明瞭さへの要求が上がっている。点数より1点あたりの質が重要になった。

プランナー案: 明文化する。「色のみに依存する識別を全種目で禁止する」。M2の地図(色 + 地域名テキストの併記)、M5の包み紙の模様と分類軸に波及する。M4が不採用になったため、包み紙の模様はM5が単独で用意することになった。

App Review の必須要件ではないが、ユーザーレビューでの不満に直結する領域。

Q0-5アート素材点数の上方修正を承認するか

企画書§8.2 は M5=8点 と見積もっているが、模様・フィードバック素材の計上漏れがある。M5 ≒ 14点への修正を推奨。
