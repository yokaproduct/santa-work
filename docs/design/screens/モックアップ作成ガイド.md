- 作成: 2026-09-08 / プランナー
- 目的: **この1枚を見ながら、11画面ぶんの絵が描けるようにする。**
- 元にした資料: `docs/design/screens/` の仕様書16本(**読まなくて構いません。必要な情報はここに集約しました**)

---

## 0. はじめに —— この絵が何に使われるか

**あなたが描いた絵に合わせて、developer が Unity の画面(Prefab)を組みます。**
そして**組んだ後は、あなたが Unity 上で位置やサイズを自由に微調整できます。**その調整は誰にも上書きされません。

> **つまりこの絵は「完成形」でなくて構いません。**
> **「だいたいこの配置」が伝われば十分です。**細かい数pxは後から Unity 上で動かせます。

**ただし §3 の「動かせないもの」だけは守ってください。** そこを外すと、機能が壊れるか、審査で落ちます。

## 1. キャンバスの決まりごと

| 項目 | 値 | 理由 |
|---|---|---|
| **サイズ** | **1080 × 1920 px** | iPhone を基準にした縦画面のサイズ。この比率で描いてください |
| **向き** | **縦画面のみ** | 横画面は非対応 |
| **上端 160px** | **セーフエリア。何も置かない** | ノッチ / Dynamic Island に隠れる |
| **下端 296px** | **バナー広告 + セーフエリア。何も置かない** | 広告と、ホームインジケータに隠れる |
| **実際に使える範囲** | **1080 × 1464 px** | 上下を引いた残り |

```
┌──────────────── 1080 ────────────────┐
│  上端 160px  ← ノッチ。何も置かない      │
├──────────────────────────────────────┤
│                                      │
│                                      │
│        ここに描く                     │
│        1080 × 1464                   │
│                                      │
│                                      │
├──────────────────────────────────────┤
│  下端 296px  ← 広告バナー。何も置かない  │
└──────────────────────────────────────┘
```

> **端末によって縦の長さが少し変わります。** 余った縦幅は**画面の中央部分が吸収**します。
> なので**「上端からの距離」と「下端からの距離」で考えて**ください。
> 例: ロゴは上から、ボタンは下から測る。

## 2. 全11画面に必ず載っているもの

**★印は「絶対に必要。抜けると機能しない」ものです。**

### 2.1 `Screen_Boot`(起動直後)—— **絵を描く必要なし**

### 2.4 `Screen_GamePlay`(ゲーム本編)—— **★2番目に重要**

> **★2026-09-08 更新: M1のモックアップ(`mockups/Screen_Gameplay_Letter.png`)で確定した構成です。**
> **他の3種(M2 / M3 / M5)も、HUDと時間バーの位置はこれに揃えます。**

**上から順に。**

| 位置 | 要素 | 必須 | 内容 |
|---|---|---|---|
| **HUD 左** | **ミニゲーム名** | ★ | 「てがみ しわけ」等。**いま何の仕事かを常時表示** |
| HUD | 縦の区切り線 | ★ | |
| **HUD 中** | **プレゼントのアイコン +「プレゼント」+ 数字** | ★ | 処理した件数 |
| HUD | 縦の区切り線 | ★ | |
| **HUD 中右** | **「COMBO」+ 数字** | ★ | **3以上のときだけ出る** |
| **HUD 右端** | **ポーズボタン** | ★ | **モックアップに無かったので仮置きです。位置は後で調整できます** |
| **HUD の下辺** | **のこり時間バー(90秒)** | ★ | **HUDとゲーム画面の区切り線が、そのまま時間バーになります。**緑→黄→赤 |
| 中央 | **ミニゲームが入る大きな枠** | ★ | ここに4種のミニゲームが差し替わる(**1080 × 1134 px**) |

> **90秒バー = 画面のいちばん上(HUDの下辺)。12秒バー = 画面のいちばん下。**

> **⚠ スコアの数字は出しません。** 正解のたびに「+120」が浮かぶだけです。
> 画面の情報を減らして、ゲームに集中させるためです。

> **⚠ 90秒バーには「背景の帯」を必ず描いてください。**
> バーが減って短くなったとき、背景が無いと**HUDとゲーム画面の境目そのものが消えてしまいます。**

## 3. ★動かせないもの / 自由に決めてよいもの

**このガイドで最も重要な部分です。**

### 3.1 自由に決めてよいもの(あなたの所有物)

| 項目 | 補足 |
|---|---|
| **要素の位置** | 上下左右どこでも |
| **要素の大きさ**(下の最小サイズを下回らなければ) | |
| **色・フォント・文字の大きさ** | |
| **背景・イラスト・装飾** | |
| **要素の重なり順** | |

> **これらは Unity 上でも後から自由に動かせます。** 動かした結果は誰にも上書きされません。
> **絵の段階で完璧を目指す必要はありません。**

### 3.2 ★動かせないもの(守らないと壊れる)

| # | 制約 | 値 | **守らないとどうなるか** |
|---|---|---|---|
| **1** | **指で押すものの最小サイズ** | **160 × 160 px 以上** | **押しにくい。**高速で連打するゲームなので、小さいと「理不尽」と感じられる |
| **2** | **押すもの同士の間隔** | **40 px 以上** | **隣を誤って押す。**誤答扱いになり、プレイヤーが最も強く不満を持つ |
| **3** | **上端 160px には何も置かない** | | ノッチ / Dynamic Island に隠れて見えなくなる |
| **4** | **下端 296px には何も置かない** | | **広告バナーに隠れる。**または指が広告に当たる |
| **5** | **`Screen_Result` の「もう一回」は、下端の広告から 160px 空ける** | **160 px** | **指が広告に当たる → 無効クリック → 広告アカウント停止。**本作でいちばん危険な場所 |
| **6** | **`Screen_Title` の押せる範囲も、広告から 40px 空ける** | **40 px** | 同上(画面全体が押せる画面のため) |
| **7** | **12月の告知は「ボタンの形」にしない** | | **App Store の審査で落ちるおそれ**(機能しないUI) |
| **8** | **点滅は 1秒に2回まで** | | 光過敏性発作への配慮。速い点滅は健康被害のおそれ |
| **9** | **赤と緑を同じ画面で「区別のために」使わない** | | **最も多い色覚特性で見分けられない。**区別には形や文字も併用する |
| **10** | **時間バーは2本。見分けがつく見た目にする**(GamePlay) | | 90秒と12秒を混同すると、プレイヤーが状況を誤解する |
| **11** | **選択肢の数・位置は問題ごとに変えない** | | 目で探し直す時間が生まれ、テンポが壊れる |

> **迷ったら「指で押すものは大きく、離して置く」。** これだけ守れば大半は大丈夫です。

## 4. ミニゲーム4種の中身(`Screen_GamePlay` の枠の中)

**枠の大きさは 1080 × 約1124 px。** HUD と進捗ドットの下、広告の上です。

| 種目 | 上半分(お題) | 下半分(指で押すところ) |
|---|---|---|
| **M1 手紙** | 手紙の便箋(本文だけ。最大3行) | **カード4枚**(2列×2行)。**絵だけ。文字は入れない** |
| **M2 住所** | 荷物の絵 + 国旗 + 国名のラベル | **世界地図。6つの地域** |
| **M3 重さ** | そりとトナカイ + 目標の数字 + 積みぐあいのメーター | **箱6個**(3列×2行)。**箱に数字が直接書いてある** |
| **M5 ラッピング** | 縦に流れるベルトコンベア(箱が3個見える) | **シュート3口** + **その下に横長のスキップ口** |

**共通のきまり**

- **押すものは必ず画面の下半分に。** 親指が届く範囲です。
- **選択肢の数は固定。** M1は常に4枚、M2は常に6地域、M3は常に6箱、M5は常に3口+スキップ口。
- **M3のトナカイの表情は「演出」ではなく「機能」です。** 積みすぎたことを伝える唯一の手段なので、
  **通常と悲しい顔の2種類が必要**です。

## 5. 必要な素材の一覧

### 5.1 ★これだけは代替がききません

| 素材 | なぜ代替不可か |
|---|---|
| **世界地図(6地域をそれぞれ別ファイルで)** | **1枚の絵だと、地域ごとに「押せる / 色が変わる / 数字が出る」ができません。**アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニアを**別々のファイル**にしてください。**これが無いとM2は動作確認すらできません** |

**地図を作るときの2つの条件**

1. **6地域を別ファイルに。** 州の区分線は別レイヤーか、地域どうしが接することで見えるように
2. **小さい地域を実際より大きくデフォルメして。** **ヨーロッパとオセアニアが小さすぎると押せません**
   (輪郭の内側だけが押せる仕組みのため、輪郭の大きさ = 押しやすさ)
3. **国境線は描かない。国名も書かない。** 領土問題のある地域の帰属を表明することになり、
   **特定の国で配信停止になるおそれ**があります。**州の区分線だけ**描いてください

### 5.2 仮の絵で先に進められるもの

**下の素材は、developer が「仮の四角」や「名前を書いただけの絵」で先に組めます。**
**あとから本物に差し替えれば大丈夫です。急ぐ必要はありません。**

| 素材 | 点数 | 備考 |
|---|---|---|
| 国旗 | 10 | **必ず正確なもの**(パブリックドメイン / CC0)。**生成AIで描かせない** |
| M1 の在庫アイコン | 20形状 | **名前を書かないので、絵だけで何か分かる明瞭さが必要** |
| 手紙の便箋 | 1 | |
| M3 の箱・そり・トナカイ・メーター | 10 | **トナカイの表情2種は必須** |
| M5 のベルト・シュート・スキップ口 | 3 | |
| M5 の形 | 6 | まる / さんかく / しかく / ほし / ハート / つき |
| M5 の模様 | 3 | 水玉 / ストライプ / チェック。**色が見分けられない人のため** |
| M5 のゴミ | 1 | つぶれた箱 + 大きな ✗ |
| **初出カードの説明絵** | **4** | 4種のルールを絵1枚で伝える |
| ランクの称号アイコン | 5 | |
| 背景 | 4 | タイトル / 工場 / 結果 / 汎用 |
| UI部品(ボタン枠など) | 30 | **角丸などは画像ファイルで用意**(コードで作らない) |
| キャラクター(サンタ・トナカイ) | 10 | |

| # | 項目 | なぜ止まるか |

## 6. どれから描くと開発が進むか(優先順位)

| 順 | 画面 | 理由 |
|---|---|---|
| **1** | **`Screen_GamePlay`** | **ゲームの本体。**ここが動かないと何も検証できません。HUD の配置が決まれば実装に入れます |
| **2** | **`Screen_ModeSelect`** | **実質的なホーム画面。**ここからゲームに入るので、動作確認の入口になります |
| **3** | **M2 住所(世界地図)** | **地図の素材が最大のボトルネック。**他より早く着手する価値があります |
| **4** | **`Screen_Result`** | プレイのループ(遊ぶ → 結果 → もう一回)を閉じるのに必要 |
| 5 | M1 手紙 / M3 重さ / M5 ラッピング | ミニゲーム3種。仮の絵で先に組めます |
| 6 | `Screen_Title` | **ロゴが決まってから。**正式タイトル待ち |
| 7 | `Overlay_Countdown` / `Overlay_Pause` / `Overlay_MicroGameIntro` | 部品が小さく、後から足しても崩れません |
| 8 | `Screen_Settings` / `Screen_Credits` / `Overlay_Confirm` | **リスト形式なので、1行の絵があれば十分。**いちばん最後で構いません |

> **1〜4 が描ければ、「起動 → 遊ぶ → 結果 → もう一回」が一通り動く状態になります。**
