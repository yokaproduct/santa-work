## 4. 処理内容

### 4.1 画面に入ったとき

```
1. SaveManager から volume.bgm / volume.se / language を読んで各行に反映
2. UMP に「同意フォームが利用可能か」を問い合わせる
     ・利用可能   → Row_Privacy を Content に追加(または SetActive(true))
     ・利用不可   → Row_Privacy を出さない
   ★LayoutGroup なので、行の増減で下の行が自動的に詰まる。これは意図した挙動
3. Application.version を Row_Version に反映
4. BGM は bgm_title のまま(切り替えない)
5. AdDisplayPolicy に従いバナーを表示する(★この画面は表示する)
```

> **★2026-09-16 最小構成で行う処理**: 1(`volume.bgm` / `volume.se` をスライダーへ、いまの言語を S3 のボタンの文字へ)・4・5 だけ。
> **2(UMP)と 3(バージョン)は後回し**(該当する行が無いため)。
> **「開いた元の画面」を覚えておく**(S0 の戻り先。今回は `Screen_Title` 固定でよい。§7-9)。

### 4.2 各要素を操作したとき

| 要素 | 操作 | 処理 |
|---|---|---|
| `BackButton` | タップ | ① `se_button` ② **開いた元の画面へ**(★2026-09-16: 今回は `Screen_Title`)。BGM は切り替えない |
| S1 BGMスライダー | ドラッグ / タップ | ① **BGM音量を `AudioManager` に即座に反映**(耳で確認できるように。鳴っている `bgm_title` の音量がその場で変わる)② **離した時点で** `SaveManager` に保存。★実際の音量は §4.5 の計算になる |
| S2 SEスライダー | ドラッグ / タップ | ① **SE音量を `AudioManager` に即座に反映** ② **離した時点で `se_tap` を鳴らして音量を聴かせる**(★実装: `se_tap` が未登録のため **`se_correct` で代用**。`se_tap` の素材が入ったら差し替える)③ 保存。★実際の音量は §4.5 の計算になる |

```
6. 画面をリロードして表示を更新する
```

> **`santa.firstLaunchDone` も消えるので、次回起動時にチュートリアルが再表示される。**
> **これは意図した挙動**(初期状態に戻す、という意味では正しい)。

### 4.5 ★スライダーの値と実際の音量(2026-09-16 追加)

> **【2026-09-16 ディレクター決定】全体の音量を約7割にする。**
> **スライダーの値(初期値 1.0)は変えず、`AudioManager` の全体倍率(既定 0.7)で下げる。**詳細は共通仕様 §11.4。

```
実際のBGM音量 = BGMスライダーの値 × BGMの基準倍率(0.6) × 全体倍率(0.7)
実際のSE音量  = SEスライダーの値  ×                         全体倍率(0.7)
```

| スライダー | 実際の音量(スライダーが初期値 1.0 のとき) |
|---|---|
| BGM | **0.42**(= 1.0 × 0.6 × 0.7) |
| SE | **0.70**(= 1.0 × 0.7) |

- **スライダーに見せる値・保存する値(`santa.volume.bgm` / `.se`)は、倍率を掛ける前の 0.0〜1.0。**倍率はプレイヤーに見せない。
- スライダーの横に数値(`ValueText`)を出す場合は、**スライダーの値 × 100 の整数**(初期値なら「100」)。倍率を掛けた値は出さない。
- **スライダーを最大にしても、全体倍率より大きくはならない。**(実機で小さすぎる場合は、スライダーではなく全体倍率を Inspector で上げる)
